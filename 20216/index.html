하루 기록 다이어리

오늘 시간을 어떻게 쓸지 계획하고, 실제로 쓴 시간을 적어 둘 사이의 차이를 돌아봐요. 잘하고 못하고를 매기지 않아요.

이 환경에서는 브라우저 저장 공간을 쓸 수 없어 기록이 저장되지 않아요. 계획과 시간 계산은 그대로 쓸 수 있지만, 페이지를 닫으면 입력한 내용이 사라져요.

입력하면 바로 이 브라우저에 자동 저장돼요(24시간을 넘는 등 잘못된 입력은 저장하지 않고, 입력칸을 벗어날 때 알려 줘요). 다른 기기·다른 브라우저와는 공유되지 않고, 브라우저 저장 공간을 지우면 기록도 사라져요. 기록은 오늘을 포함한 달력상 최근 7일 것만 보관하고, 그보다 오래된 날짜의 기록은 자동으로 지워져요. 이름·학교 같은 개인정보는 입력받지 않아요.

하루 계획

예시 계획은 참고용 한 가지 예일 뿐, 모든 학생에게 맞는 시간표가 아니에요. 불러오면 바로 자동 저장되니, 자기 상황에 맞게 고쳐 쓰세요.

실제 기록

실제 기록이 자동 저장돼도 계획은 바뀌지 않아요. 계획과 다른 활동에는 이유와 메모를 남길 수 있어요. 시간·이유를 고치거나 '확인'을 누른 활동만 실제 기록이 되고, 손대지 않은 활동은 '미확인 · 기본값'으로 남아요.

기록 비교

오늘을 포함한 달력상 최근 7일 중 날짜를 고르면 그날의 계획과 실제 시간을 비교해 보여 줘요. 차이 = 실제 시간 − 계획 시간이에요.
