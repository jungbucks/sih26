마인크래프트 다단계 아이템 재료 계산기

만들 아이템과 개수를 고르면, 창고에서 챙길 기본 원재료와 단계별 조합 순서를 한 번에 계산해 줘요.

기준: Minecraft Java Edition 기본 작업대 조합법

무엇을 몇 개 만들까요?

빠르게 해 보기

만들 아이템과 개수(1~999)를 입력하고 [계산하기]를 눌러 주세요.

다른 방법으로 얻을 수도 있어요

직접 확인해 볼 테스트 표 열기
상황입력·조작기대 결과
정상 (올림·세트 단위) 책장 11개 계산 판자 66개 (1세트 + 2개, 실제 68개 제작·남는 재료 +2개), 책 33개, 종이 99개 (1세트 + 35개) / 기본 원재료: 원목 17개, 가죽 33개, 사탕수수 99개 (1세트 + 35개)
경계 (1개·999개) 피스톤 1개 계산 후 999개 계산 1개: 판자 3개 → 원목 1개 (판자 4개 제작, 남는 재료 +1개), 조약돌 4개, 철괴 1개, 레드스톤 가루 1개 / 999개: 원목 750개 (11세트 + 46개), 판자 3000개 제작·남는 재료 +3개
잘못된 입력·연타 빈칸, 0, -5, 1000 입력 / 정상 숫자로 [계산하기] 5번 연속 안내 문구가 뜨고 계산하지 않음 / 결과는 한 벌만 보임

이 계산기는 입력한 내용을 브라우저에 저장하지 않아요. [초기화]나 새로고침을 하면 처음 화면으로 돌아가요.
